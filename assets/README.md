# WordPress.org 用アセット（プラグイン本体には含めない）

このフォルダの画像は **WordPress.org プラグインディレクトリの表示専用** です。
配布される plugin.zip（trunk のプラグイン本体）には **含めません**。
登録後、SVN リポジトリの **`/assets/` ディレクトリ**（`/trunk/`・`/tags/` と同階層）にアップロードします。

```
<svn-root>/
├── assets/   ← この中の画像をここに置く
├── trunk/    ← プラグイン本体（link-map-insights-official の中身）
└── tags/
```

## 用意するファイルと推奨サイズ

### アイコン（正方形）
- [ ] `icon-128x128.png` … 128 × 128
- [ ] `icon-256x256.png` … 256 × 256（高解像度用）
- [ ] （任意）`icon.svg` … ベクター版

### バナー（横長・上部にプラグイン名が重なるので要素は中央〜左寄せ）
- [ ] `banner-772x250.png` … 772 × 250
- [ ] `banner-1544x500.png` … 1544 × 500（高解像度用）

### スクリーンショット（番号は readme.txt の == Screenshots == と対応）
- [ ] `screenshot-1.png` … 内部リンクマップの表示画面（推奨幅 1200px 前後）
- [ ] `screenshot-2.png` … 被リンクゼロ・発リンクゼロのページ一覧

## メモ
- 形式は PNG 推奨（透過が必要なアイコン・バナーは特に）。JPG も可。
- スクリーンショットのキャプションは `readme.txt` 側で管理（現状2件記載済み）。
- 画像を増やす場合は readme.txt の `== Screenshots ==` に行を追加し、番号を一致させること。
```
== Screenshots ==

1. 内部リンクマップの表示画面
2. 被リンクゼロ・発リンクゼロのページ一覧
```
