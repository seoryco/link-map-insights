# Link Map Insights

A WordPress plugin that visualizes your site's internal link structure as an interactive network graph in one click, and lists pages with no inbound or outbound links.

**Install it from WordPress.org:** https://wordpress.org/plugins/link-map-insights/

- Requires WordPress 5.0 or later and PHP 7.4 or later
- Full documentation: [`readme.txt`](readme.txt)

## About this repository

This is the source of the plugin as published on WordPress.org. Releases are deployed to the WordPress.org plugin SVN; the tags here (`v1.1.0`, `v1.2.1`, `v1.3.0`, …) match the released versions. `assets/` holds the WordPress.org directory images (icon and banners), which are deployed to the SVN `assets/` directory, not to the plugin itself.

The network graph uses a bundled copy of [vis-network](https://github.com/visjs/vis-network) (see `readme.txt` for the version and source).
